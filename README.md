# Bug Meme Roaster

**TL;DR:** A VS Code extension that displays Incredibles-themed images based on how many bugs are currently in your code.

---

## Why This Project Exists

Built as a lightweight VS Code extension that reacts to your current error count in real time, giving passive feedback on code quality as you work.

## What It Does

Watches your code for errors in real time and displays different images based on how many bugs are currently present.

## Key Features

- **Real-time error watching** — tracks bugs in your code as you write it
- **Image escalation** — displays different images depending on how many bugs are currently present
- **Passive feedback loop** — gives an at-a-glance signal of code health while coding
